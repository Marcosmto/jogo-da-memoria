## 📋 Sobre o Projeto

Jogo clássico da memória com cartas de tecnologias web. O objetivo é encontrar todos os pares de ícones.

### Tecnologias representadas nas cartas:

`HTML` · `CSS` · `JavaScript` · `React` · `Node.js` · `MongoDB` · `Firebase` · `Bootstrap` · `jQuery` · `Electron`

### Funcionalidades:

- Embaralhamento aleatório das cartas a cada partida
- Animação de virar carta (CSS 3D)
- Bloqueio de clique durante verificação de par
- Tela de vitória ao completar o jogo
- Botão para reiniciar a partida
